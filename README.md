# Conta Clara

Calculadora aritmética reativa feita com Vue 3 e Vite. O resultado é atualizado automaticamente ao alterar os números ou a operação.

## Requisitos

- Node.js 20.19+ ou 22.12+
- npm

## Executar

```bash
npm install
npm run dev
```

## Testes e build

```bash
npm test
npm run build
```

A calculadora oferece adição, subtração, multiplicação e divisão. Campos vazios aguardam entrada e divisão por zero é sinalizada na interface.
